# HeartDays 心历 – Legal pages

Static Privacy Policy and Terms of Use (English / 简体中文 / 繁體中文), generated from `../App/Legal/*.md`.

1. Fill in your real details and rebuild:
   `python3 build.py --name "Your Name" --email you@example.com --law "the laws of …" --court "the court of …"`
2. Push this folder's contents to a new public GitHub repo (e.g. `gooddays-legal`).
3. Repo → Settings → Pages → Deploy from branch `main`, folder `/ (root)`.
4. In App Store Connect use:
   - Privacy Policy URL: `https://<user>.github.io/gooddays-legal/privacy-en.html`
   - (Optional) Terms of Use (EULA) link in the description: `https://<user>.github.io/gooddays-legal/terms-en.html`
